# ClassCompass Frontend

React SPA (Shadcn UI + Tailwind)

Start locally:

Copy and rename the `.env.example` file to `.env`. Edit the `.env` file to set API URLs or your domain.

```bash
pnpm install

pnpm run dev
```

Generate API client (if needed):

```bash
pnpm run generate
```
