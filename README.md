# ClassCompass Frontend

React SPA (Shadcn UI + Tailwind) frontend for the ClassCompass platform.

## Start locally

Copy over the env example to `.env` and edit the values where needed.

```bash
pnpm install

pnpm run dev
```

Generate API client (if needed):

```bash
pnpm run generate
```
